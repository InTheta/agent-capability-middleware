# ACM SDK v0.1.0-preview.25

This preview packages the reviewed Omni pricing and paid MCP contract from
`24e9f85b`: news recipes bind 0.010 USDC, and `consumeX402McpTestnet` accepts
`get_premarket_roundup` at an explicitly pinned 0.100 USDC. Entity resolution
remains 0.001 USDC. These changes were source-only after preview.24; this version
makes them available through the versioned GitHub package once its tag is published.

## Install and verify without payment

The following commands require publication of `v0.1.0-preview.25`:

```sh
npx --yes https://github.com/InTheta/agent-capability-middleware/archive/refs/tags/v0.1.0-preview.25.tar.gz doctor
npx --yes https://github.com/InTheta/agent-capability-middleware/archive/refs/tags/v0.1.0-preview.25.tar.gz demo buyer
npm install github:InTheta/agent-capability-middleware#v0.1.0-preview.25
```

The doctor inspects nine HTTP route templates and the 0.010 USDC Base Sepolia
market-risk quote. This is the SDK's subset of Omni's thirteen HTTP products;
it does not test paid responses. The paid MCP union now covers five tools,
including published premarket research. The premarket HTTP route and three PNG
routes are not typed HTTP recipes in this package. The buyer demo uses mock
settlement. These commands use no payer key and spend no USDC.

## Distribution and verification boundary

This is a GitHub-distributed developer preview, not an npm publication, hosted
gateway, trading credential, mainnet authorization, or new funded-test result.
The SDK never receives a payer private key. Protected gateway access, an approved
exact grant, current expected-payment constraints, and separate human spending
authorization remain prerequisites for paid calls. Preview.24 is immutable;
do not move its tag or use its historical news recipe for current-price purchases.

The release candidate must pass `npm run verify` and `npm run artifact:check`,
including consumer typechecks, focused pricing/MCP tests, package smoke, and the
clean-room packed mock lifecycle. After publishing the exact CI-qualified commit,
verify the immutable archive in a clean consumer and run the no-spend doctor and
mock buyer demo. A prepared PR or local packed install alone does not prove the
GitHub release is published or that current funded settlement works.

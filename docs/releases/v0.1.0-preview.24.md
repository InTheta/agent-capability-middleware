# ACM SDK v0.1.0-preview.24

This release includes the already-reviewed Omni pricing correction from 4ce7811
in a new immutable public tag. Preview.23 remains historical and still expects
3000 atomic USDC for the market-risk quote; the current route quotes 10000.

## Install and verify without payment

```sh
npx --yes https://github.com/InTheta/agent-capability-middleware/archive/refs/tags/v0.1.0-preview.24.tar.gz doctor
npx --yes https://github.com/InTheta/agent-capability-middleware/archive/refs/tags/v0.1.0-preview.24.tar.gz demo buyer
npm install github:InTheta/agent-capability-middleware#v0.1.0-preview.24
```

The doctor checks nine canonical route templates and the 0.010 USDC Base Sepolia
market-risk quote. Nine is this CLI's subset, not the complete Omni product count.
The buyer demo uses mock settlement. Neither command pays or uses a private key.

The public API and custody boundary are unchanged. This is a GitHub-distributed
developer preview, not an npm publication, hosted gateway, mainnet authorisation,
independent assurance result or proof of customer demand. Upgrading does not enable
spending. Active installation docs point to this tag; old tags are not moved.
Release verification uses CI source/consumer tests, packed installs, generated
artifact checks and the published archive's live no-spend doctor and buyer demo.
